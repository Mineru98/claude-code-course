# Claude Code 구성 요소 수업

Claude Code의 핵심 구성 요소를 주제별 브랜치로 나누어 학습하는 저장소입니다.
아래에서 원하는 주제의 브랜치로 이동하세요.

## 수업 목차 (브랜치별 라우팅)

| 주제 | 설명 | 브랜치 |
| ---- | ---- | ------ |
| 🪝 Hooks | Claude Code 훅(Hooks) 구성과 활용 | [course/hooks](https://github.com/Mineru98/claude-code-course/tree/course/hooks) |
| 🤖 Agents | 서브에이전트(Subagents) 정의와 사용 | [course/agents](https://github.com/Mineru98/claude-code-course/tree/course/agents) |
| 👥 Agent Teams | 다중 에이전트 협업(Agent Teams)과 오케스트레이션 | [course/agent-teams](https://github.com/Mineru98/claude-code-course/tree/course/agent-teams) |

> 각 브랜치에는 해당 주제의 예제 코드와 설명이 포함되어 있습니다.
> 브랜치 링크를 누르면 GitHub에서 바로 해당 수업 내용을 확인할 수 있습니다.
